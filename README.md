# EcoIndex (Web audit Module)

EcoIndex module for web-audit.

## Install
1. Install with your favorite package manager
2. Add the module in your web-audit.config.js 
```
export const config = {
	modules: [
        ...
        'node_modules/web-audit-module-ecoindex/src/modules/EcoIndexModule.js'
    ],
},
```
